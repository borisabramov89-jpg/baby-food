🚀 התקנה – שלב אחר שלב

1חשבונות GitHub
כל אחד מכם פותח חשבון ב-github.com (אישי, לא של העבודה). אפשר גם חשבון אחד משותף – ואז מדלגים על שלב 4.
2ריפו האתר (ציבורי)
  1. לוחצים + ← New repository ← שם: baby-food ← Public ← Create.
  2. Add file ← Upload files ← גוררים את כל התוכן של התיקייה site-repo (כולל .nojekyll) ← Commit changes.
    אם .nojekyll לא נגרר (קובץ מוסתר) – זה לא קריטי, האתר יעבוד גם בלעדיו.
  3. Settings ← Pages ← Source: Deploy from a branch ← Branch: main / (root) ← Save.
  4. אחרי 1–2 דקות תופיע הכתובת: https://USERNAME.github.io/baby-food/
ב-HTML אין שום מידע אישי, ולכן זה בסדר שהריפו הזה ציבורי (בחשבון חינמי, Pages עובד רק מריפו ציבורי).
3ריפו הנתונים (פרטי)
  1. New repository ← שם: baby-food-data ← 🔒 Private ← Create.
  2. Upload files ← מעלים את data.json ואת README.md מתוך data-repo ← Commit.
    גם אם לא תעלו את data.json, האפליקציה תיצור אותו לבד בשמירה הראשונה (בתנאי שבריפו יש לפחות קובץ אחד, למשל README).
4הוספת בן/בת הזוג לריפו הפרטי
בריפו baby-food-data: Settings ← Collaborators ← Add people ← שם המשתמש שלה ← היא מאשרת את ההזמנה במייל.
5יצירת טוקן אישי (כל אחד את שלו)
  1. תמונת הפרופיל ← Settings ← Developer settings ← Personal access tokens ← Fine-grained tokens ← Generate new token.
  2. Token name: baby-food · Expiration: לבחור תוקף (מומלץ שנה, או No expiration).
  3. Resource owner: הבעלים של baby-food-data.
    אצל בת הזוג: אם הריפו בבעלותך, ייתכן שהיא לא תוכל לבחור אותו בטוקן Fine-grained. במקרה כזה: Tokens (classic) עם הרשאת repo, או להשתמש באותו טוקן משני מכשירים (פחות מומלץ), או חשבון משותף.
  4. Repository access: Only select repositories ← baby-food-data בלבד.
  5. Permissions ← Repository permissions ← Contents: Read and write.
  6. Generate token ← להעתיק מיד (מתחיל ב-github_pat_). הוא מוצג פעם אחת בלבד.
6חיבור האפליקציה (אצלך)
  1. פותחים https://USERNAME.github.io/baby-food/ ← לשונית ⚙️ הגדרות וסנכרון.
  2. ממלאים: שם משתמש GitHub (בעל הריפו), ריפו baby-food-data, ענף main, קובץ data.json, והטוקן.
  3. 🧪 בדיקת חיבור ← צריך להופיע ✅ ו-🔒 "הריפו פרטי". ← 🔌 שמור והתחבר.
  4. ממלאים פרטי תינוק ושמות ההורים ← שמור ← בוחרים את השם שלך בראש המסך ("משתמש/ת נוכחי/ת").
7חיבור אצל בן/בת הזוג
  1. אצלך: 🔗 העתק קישור הגדרה ← שולחים לה (הקישור לא כולל את הטוקן).
  2. היא פותחת את הקישור ← הפרטים כבר ממולאים ← מדביקה את הטוקן שלה ← שמור והתחבר ← בוחרת את השם שלה למעלה.
8אפליקציה על מסך הבית בטלפון
iPhone (Safari): כפתור שיתוף ← "הוסף למסך הבית". · Android (Chrome): ⋮ ← "הוסף למסך הבית" / "התקן אפליקציה".
בכל מכשיר חדש מדביקים את הטוקן פעם אחת.

🔄 איך הסנכרון עובד

  • סנכרון אוטומטי כל 20 שניות, מיד אחרי כל שמירה, ובכל חזרה לאפליקציה. הנקודה בראש המסך: 🟢 מסונכרן · 🟡 מסנכרן · 🔴 שגיאה.
  • מיזוג לפי רשומה: אם שניכם מתעדים באותו זמן – שני הרישומים נשמרים. אם שניכם עורכים אותה רשומה – העריכה האחרונה קובעת.
  • בלי אינטרנט – ממשיכים לתעד, והכול נשלח בחיבור הבא.
  • כל שמירה = commit בריפו הפרטי. לשחזור: בריפו ← data.json ← History.

🔐 אבטחה

  • לעולם לא לשים את הטוקן בתוך index.html או בריפו – האתר ציבורי.
  • הטוקן נשמר רק בדפדפן של המכשיר. מכשיר שאבד: GitHub ← Settings ← Developer settings ← למחוק את הטוקן וליצור חדש.
  • לוודא שריפו הנתונים פרטי (בדיקת החיבור מתריעה אם לא).
  • לא להשתמש ב-Gist "סודי" לנתונים – הוא נגיש לכל מי שיש לו קישור.

🛠️ תקלות נפוצות

הודעהפתרון
הטוקן לא תקין או שפג תוקפו (401)ליצור טוקן חדש ולהדביק בהגדרות.
אין הרשאה (403)בטוקן: Contents = Read and write, והריפו הנכון נבחר.
הריפו לא נמצא (404)לבדוק איות של שם המשתמש והריפו, ושהטוקן מורשה לריפו. אצל בת הזוג – שאישרה את הזמנת ה-Collaborator.
האתר מציג 404לחכות 2 דקות אחרי הפעלת Pages; לוודא ש-index.html נמצא בשורש הריפו (לא בתוך תיקייה).
הנתונים לא מופיעים במכשיר השניללחוץ 🔄 "סנכרן עכשיו"; לוודא ששני המכשירים מחוברים לאותו owner/repo.
